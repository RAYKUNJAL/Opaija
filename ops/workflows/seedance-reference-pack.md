# Seedance Reference Pack Standard

Every major character packet should contain:

- Full-body model sheet
- Face sheet
- Expressions
- Turnaround views
- Action pose
- Relaxed pose
- Props and weapons
- Color palette
- Height scale
- Profile block
- Seedance prompt with style lock
- Negative prompt with drift warnings

## Prompt Lock

Use this production description unless a character-specific packet overrides it:

`2.5D Caribbean anime hybrid, clean professional animated series model sheet, Afro-Caribbean facial structure, rounded chin, full lips, distinct broad nose design, bright island energy, detailed clothing tied to Trinidad and Tobago Kalenda/Calinda culture, black ink linework, controlled gold/orange/red/teal accents, cinematic but duplicable production style, no generic fantasy armor, no washed-out palette.`

## Background Removal

Transparent PNG cutouts are useful for the command center, thumbnails, packaging, and motion graphics, but they are not required for Seedance if the model sheet is clean and readable. Use transparent cutouts for thumbnails and compositing; keep full model sheets for animation references.
