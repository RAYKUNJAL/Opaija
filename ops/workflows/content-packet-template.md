# OPAIJA Content Packet Template

## Packet ID

`OPAIJA-YYYYMMDD-###`

## Content Type

- Character reveal
- Lore teaser
- Vertical micro-episode
- Pilot scene
- Behind-the-scenes art post
- Merch test

## Required Inputs

- Character bible section
- Model sheet or shot reference
- Canon memory notes
- Hook line
- Narrator script
- Visual prompt
- Caption and hashtags
- Export target

## Approval Gates

1. Canon check
2. Visual consistency check
3. Cultural language check
4. Platform packaging check
5. Final post-production check

## Output Files

- `script.md`
- `shot-list.md`
- `video-prompts.md`
- `caption.md`
- `thumbnail-brief.md`
- `qc.md`
