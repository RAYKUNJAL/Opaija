## 🔄 THE 7-STAGE PIPELINE (`scripts/produce.ts`)

```
parse → voice → prompts → clips → manifest → render → report
```

| # | Stage | What it does | Output |
|---|-------|--------------|--------|
| 1 | **parse** | Reads episode script from `episodes/epNN/` or `QUEUE.json`, splits into timed beats | `ParsedScript` (beats, characters, runtime) |
| 2 | **voice** | Sends narrator script to ElevenLabs → MP3 + word-level alignment | `narration.mp3`, `alignment.json`, `.srt` |
| 3 | **prompts** | Builds per-beat Seedance prompts (text + negative + reference images) | `PromptedBeat[]` |
| 4 | **clips** | Submits each beat to fal.ai Seedance → 5s video clips (mock if no key) | `clips/*.mp4` |
| 5 | **manifest** | Builds Remotion composition manifest (long-form 16:9 + vertical 9:16) | `manifest.json` |
| 6 | **render** | Remotion renders final MP4s | `out/<EPxxx>.mp4` |
| 7 | **report** | Spend report, timing audit, canon QA checklist | `report.json` |

**Run an episode end-to-end:**

```bash
npx tsx scripts/produce.ts EP001                 # produce episode 1
npx tsx scripts/produce.ts EP001 --force         # re-run every stage
npx tsx scripts/produce.ts EP002 --from=clips    # resume from clips stage
npx tsx scripts/produce.ts EP002 --aspect=9:16   # vertical short (default)
npx tsx scripts/produce.ts EP002 --aspect=16:9   # YouTube long-form
npx tsx scripts/produce.ts EP002 --quality       # cost-mode: quality
```

Missing API keys drop the relevant stage into MOCK MODE so downstream stages still have valid inputs.

## 🐝 THE SWARM (3-LAYER MEMORY)

Every agent in the roster (`ops/agents/AGENT_ROSTER.yaml`) follows the same **6-step memory loop** on each invocation:

```
1. LOAD    context (CANON_MEMORY.json + LEARNINGS.jsonl filtered to self
            + new MESSAGE_BUS entries addressed to self + EPISODE_STATE.json)
2. DO      this agent's job
3. WRITE   output artifacts to episodes/epNN/
4. POST    to MESSAGE_BUS.jsonl — what was done, what's next, who's next
5. LEARN   if corrected, append to LEARNINGS.jsonl
6. UPDATE  EPISODE_STATE.json stage/flags for the next agent's gate
```

**The 3 memory layers:**

| Layer | File | Who writes | Who reads |
|-------|------|-----------|-----------|
| **MESSAGE_BUS** | `memory/MESSAGE_BUS.jsonl` | Every agent (append-only) | Next agent in pipeline |
| **LEARNINGS** | `memory/LEARNINGS.jsonl` | Any agent that was corrected | All agents (filtered to self) |
| **CANON_MEMORY** | `memory/CANON_MEMORY.json` | `scripts/generate-canon-memory.ts` (generated) | All agents (read-only) |

> **You edit `data/shared-memory/OPAIJA_CANON.json` (human). Agents read `memory/CANON_MEMORY.json` (machine).** Never edit the generated file by hand — re-run the generator after any canon change:
> ```bash
> npx tsx scripts/generate-canon-memory.ts
> ```

**Agent roster (20 agents):** canon-guardian, orchestrator, script-writer, character-bible-writer, visual-design-agent, storyboard-agent, seedance-packager, voice-director, remotion-editor, render-agent, qa-agent, social-scheduler, action-choreographer, cinematic-fx-director, analytics-agent, lore-guardian, archive-clerk, tribe-growth-commander, merch-asset-agent, book-agent.

**Pipeline DAG (orchestrator fires in this order per episode):**

```
script_draft → canon_review → visual_prep → voice → clips → manifest → render → qa → publish
```

Run the swarm:

```bash
npx tsx scripts/swarm-orchestrator.ts EP001          # continuous loop
npx tsx scripts/swarm-orchestrator.ts EP001 --dry-run # show what would fire
npx tsx scripts/swarm-orchestrator.ts EP001 --once     # fire one agent and exit
```
