# OPAIJA Style Guide

This is the working style lock for future Opaija characters and generated media.

## Core Visual Identity

Opaija is a `2.5D Caribbean anime hybrid`: clean anime readability, African/Caribbean facial features, island streetwear, Kalenda/Calinda combat culture, and bright Trinidad/Tobago energy.

## Character Face Rules

- Rounded chins, not pointed V-shaped generic anime chins.
- Full lips with character-specific shape.
- Broad African/Caribbean nose structures with individual variation.
- Warm, expressive eyes and readable expressions.
- Hair should be brandable: locs, wraps, beads, shells, braid patterns, island color accents, and culture-specific silhouettes.

## Model Sheet Standard

Every recurring character needs:

- Turnaround views
- Action pose
- Relaxed pose
- Casual pose
- Head angles
- Expressions
- Key details and gear
- Color palette
- Profile
- Scale and notes
- Signature line
- Seedance prompt
- Remotion/editing notes

## Brand Memory Prompt

Use this prompt core for all new characters:

```text
Create in the locked OPAIJA 2.5D Caribbean anime hybrid style: rounded chin, full lips, broad African/Caribbean nose language, expressive warm eyes, clean black ink linework, bright island energy, modern Caribbean streetwear fused with Kalenda/Calinda and Carnival-inspired details, controlled gold/orange/red/teal/cream accents, professional animated series model sheet clarity, duplicable proportions for Seedance and Remotion.
```

## Never Drift Into

- Generic fantasy armor
- Washed-out muted palettes
- Thin generic anime facial features
- Random symbols that fight the Opaija mark system
- Non-specific "island" styling without Trinidad/Tobago or Caribbean cultural grounding
